# Flat Roblox import folder

56 individual FBX exports in this one folder:

- Tier 2: 5 landmark buildings.
- Tier 3: 27 buildings (10 old, 9 modern, 5 mixed-use, 3 informal).
- Riverfront: 7 support modules, 15 props and 2 context structures.

Howrah Bridge and the main ghat are intentionally kept separate:

- `../../assets/kolkata/howrah_bridge/bridge/KOL_HBR_HOWRAH/KOL_HBR_HOWRAH.fbx`
- `../../assets/kolkata/howrah_bridge/ghat/KOL_HBR_GHAT/KOL_HBR_GHAT.fbx`

These are byte-identical convenience copies of the current saved exports, not a newly combined model. Canonical editable sources and exports remain under `assets/kolkata/`. Refresh the copies from their canonical paths after future asset edits. `import-manifest.json` records each source path and SHA-256.

Import each unique design once and reuse its imported mesh assets for future placements. Studio import/appearance/collision validation remains pending.
