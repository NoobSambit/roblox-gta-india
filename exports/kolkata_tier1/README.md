# Kolkata Tier 1 FBX exports

All 46 final FBXs are in this folder. Select the files sharing one prefix and
import them together: `KOL_T1_ATMOSPHERE`, `KOL_T1_TRUMP`, `KOL_T1_URBANA`,
`KOL_T1_ROYAL`, `KOL_T1_SONAR`, or `KOL_T1_JW`.

Use **Scale Unit: Stud**, **Scale Factor: 1**, **Merge Meshes: off**,
**Anchored: on**, and common scene-origin placement/pivots. Keep Upload to
Roblox off for the first import check. Do not merge the whole building.

Maximum individual mesh: **5,500 triangles**. All mesh topology/scale checks
passed; actual Studio import will be performed by the user. See the asset
manifests for dimensions, counts, materials and sockets. `SHA256SUMS.txt`
identifies these checked FBX bytes.

Editable sources, original PNG previews and verification:
[`assets/kolkata/tier1`](../../assets/kolkata/tier1/).
