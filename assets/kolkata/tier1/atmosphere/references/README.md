# ATMOSPHERE reference study

User-supplied street and aerial bridge views; completed obliques and MERO construction/structural views.

`sources.json` is the curated list of visually reviewed, relevant views. Downloads stay local in ignored `artifacts/references/tier1/atmosphere/`; photographs are not redistributed or used as game textures. User-supplied chat images are visual references and have no filesystem attachment path in this session. Rear elevations are simplified where rear evidence is unavailable.
