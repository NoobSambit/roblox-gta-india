# URBANA reference study

User-supplied aerial and street photographs; Nitson & Amitsu contractor views and developer cluster/clubhouse views.

`sources.json` is the curated list of visually reviewed, relevant views. Downloads stay local in ignored `artifacts/references/tier1/urbana/`; photographs are not redistributed or used as game textures. User-supplied chat images are visual references and have no filesystem attachment path in this session. Rear elevations are simplified where rear evidence is unavailable.
