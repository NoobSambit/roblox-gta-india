# ROYAL reference study

User-supplied front, oblique, crown and portico photographs; official gallery and additional exterior oblique/portico studies.

`sources.json` is the curated list of visually reviewed, relevant views. Downloads stay local in ignored `artifacts/references/tier1/royal/`; photographs are not redistributed or used as game textures. User-supplied chat images are visual references and have no filesystem attachment path in this session. Rear elevations are simplified where rear evidence is unavailable.
