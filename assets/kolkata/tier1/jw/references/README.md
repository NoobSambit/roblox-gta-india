# JW reference study

User-supplied aerial, night approach, low-angle entrance and facade images; the latest reminder image determines the revised proportions and rounded podium.

`sources.json` is the curated list of visually reviewed, relevant views. Downloads stay local in ignored `artifacts/references/tier1/jw/`; photographs are not redistributed or used as game textures. User-supplied chat images are visual references and have no filesystem attachment path in this session. Rear elevations are simplified where rear evidence is unavailable.
