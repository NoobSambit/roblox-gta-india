# SONAR reference study

User-supplied courtyard, pool and arrival views; official gallery and published court, facade-screen and terrace angles.

`sources.json` is the curated list of visually reviewed, relevant views. Downloads stay local in ignored `artifacts/references/tier1/sonar/`; photographs are not redistributed or used as game textures. User-supplied chat images are visual references and have no filesystem attachment path in this session. Rear elevations are simplified where rear evidence is unavailable.
